# HGhub 1.5.0：网页首页、探索与全屏切换修复

保留 Tauri + Rust + React 框架及原有播放、安全、收藏和观看记录逻辑。延续用户提供的 windows-client 的橙色强调色、深浅色、无边框桌面壳及卡片排列逻辑。

修改前备份：工作目录 `backups/20261112_125004_before_explore`，包括 1.4.1 源码包、便携包、可运行目录和 SHA256 清单。原有 1.4.1 目录保留，可退出新版后回退。

## 首页与探索

- 首页按当前原网页组织精选轮播、快捷入口、热搜词、热门标签、精选推荐、最近上新、热播和专题；若原网页返回分类推荐区，也会自动导入。卡片使用原视频 ID、简介、标签、集数、完结状态、评分、封面与热度，沿用客户端详情预览及选集播放。
- 新增独立“探索”入口：精选推荐、最近上新、热播短剧、黄果原创、短剧、漫剧、专题合集和图文社区。原创分为全部原创、原创短剧、原创漫剧。图文分类由上游实际返回，支持文章与剧评。
- 专题可分页浏览；详情包含介绍、作品和相关专题。选择作品继续使用现有详情和播放器，返回恢复原列表及分区。数据提供 FAQ 时仍支持展开阅读。
- 热门标签进入对应的原网页标签目录。探索热搜词可以换一批并打开全局搜索；排行榜、上新和分类筛选快捷入口接入原有导航。
- “放映”保留原连续视频流及频道切换。首页浏览不会自动启动隐藏视频。
- 普通文章不再生成空白播放器或虚假的播放按钮，正文沿用原有清洗及链接处理。

## 播放面积与全屏

- 普通桌面播放移除外侧留白、舞台圆角裁切、视频圆角及装饰细边框；画面铺满顶部工具栏和侧栏之外的全部内容区。视频维持等比完整显示，源视频比例产生的黑边保留。
- 全屏误切换的原因：旧代码以 `scrollTop / clientHeight` 计算当前视频。全屏、影院模式及窗口缩放改变高度后，旧像素偏移被解释成另一个条目，从而重新加载播放地址。
- 新增视口对齐逻辑，尺寸变化时以当前逻辑条目为准重定位，暂时关闭滚动吸附和锚定，等布局稳定后恢复。布局事件不能改变选中的视频；主动滚轮、按钮、键盘及拖动仍能切换条目。
- 全屏切换不重建媒体元素，不重新取址，保留视频、集数、进度、手动暂停、倍速和音量。沿用 1.4.1 的进入即隐藏、1.2 秒闲置隐藏与返回优先退出模式。

## 原网页兼容方式

本轮核对了 [官网首页](https://huangguoai.com/)、[推荐](https://huangguoai.com/recommend)、[上新](https://huangguoai.com/newest)、[原创](https://huangguoai.com/original/) 和专题等公开页面及其数据结构。

现场发现通用视频、首页列表、专题影片及标签等接口存在业务错误或间歇性失败；接口原创排序也不能可靠代表网页原创集合。因此首页及相关视频列表直接读取对应的公开网页，再提取结构化字段融入本地 React 页面。每个列表在整个翻页过程中保持同一数据源及原分页，避免混用接口每页 20 条和网页每页 40 条造成跳项。

原始页面放入未挂载的惰性 template，仅提取字段；页面脚本、事件处理器、外部框架及跟踪代码不进入运行界面。封面继续走原本地图片协议，播放使用原有 Rust 取址及媒体引擎。请求沿用当前线路、代理及网络目标检查，限制网页大小。热播榜、专题目录、热搜词、图文分类和文章继续使用验证可用的实际接口；失败会显示重试。

分类筛选的全部、短剧和漫剧视图也复用对应原网页来源；全部默认显示上新，选择具体分类后显示最近更新。热播及原创使用对应来源，题材和完结状态仍只筛选已加载作品。热播接口返回一份榜单，显示该榜单后结束，不编造分页或更多名次。
