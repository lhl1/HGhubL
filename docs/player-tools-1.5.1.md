# HGhub 1.5.1：接口评分与播放栏选集

修改前备份：工作目录 `backups/20261112_140354_before_rating_episodes`，包含 1.5.0 源码包、便携包、可运行目录及 SHA256 清单。保留 Tauri + Rust + React 框架、既有配色及全屏隐藏/返回逻辑，不覆盖旧版交付目录。

## 评分

- 播放栏显示接口综合分，点击星形分数按钮展开评分浮层。综合分及人数使用 `GET /api/videos/{id}/rating` 的 `score`、`rating_cnt`，本人评分使用 `my`。
- 按[官网评分实现](https://huangguoai.com/static/web/js/pages/cyber-video.js)接入：综合分为 10 分制；用户选择 1–5 星，对应 2–10 分，POST 发送的 `score` 是星数。界面明确显示“已选 X 分”。
- 登录后点击“提交评分”才调用评分接口；选择星数、查看分数、关闭浮层和打开登录均不提交。全屏中进入登录先退出沉浸模式，确保登录框可见。
- 已评星数由接口恢复，已确认提交后锁定；提交中防重复点击。失败保留草稿、显示错误并允许重试；只使用服务器返回值更新综合分，播放栏和视频介绍同步显示。
- 兼容数字和数字字符串；无效分数不覆盖有效详情分数，未知人数不伪装成零。切换视频、账号、页面活动状态及卸载都会隔离旧回包。
- 评分读取或提交不重建媒体、不刷新播放地址。登录引起账户播放地址更新时保存并恢复当前进度。

## 选集

- 从桌面右侧社交栏移除选集入口，放在底部播放栏，宽窗口显示当前集/总集数。
- 点击向上展开浮层，显示当前集、总集数、高亮当前集及六列剧集网格，支持按集数或标题查找、正倒序、方向键、Home/End 和回车定位。重开选集恢复完整列表。
- 选择当前集只关闭浮层；选择另一集切换同一视频的对应集数。加载中、无选集、无匹配及加载失败均有状态，重试剧集信息不重启视频。
- 浮层覆盖画面，不再让播放视口为选集侧栏缩窄；大列表在浮层内滚动，浮层限制在视频区域与屏幕边界内。评分、选集与倍速菜单互斥。
- 全屏内浮层挂载到全屏元素，菜单打开期间保持控制栏可见；关闭后恢复闲置隐藏。失焦、模式退出、切换视频和页面隐藏会收起浮层；普通窗口 Esc 先关菜单，全屏 Esc 仍优先恢复普通窗口。
- 小窗口压缩间距、隐藏次要集数文本，音量滑块悬浮展开，保留播放器可用面积。
