# 1.5.5 使用体验修复

- 修改前备份：backups/20261112_170548_before_usability，含 1.5.4 源码、便携包、可运行目录和 SHA256 清单。
- 猜你想搜：将上游单条包含多个 # / ＃ 话题的字符串拆成独立词，去重并保留较高热度；排除长标题、无效词。无可用词时尝试站点题材数据。每次显示四个独立搜索词，点击仅搜索该词；不足一批时禁用换一批。固定网格、长词省略，热度独立显示。分类页同类热搜词也适配网格。
- 外观：本次升级首次启用跟随系统（含已有旧版主题设置），后续手动选择深/浅色仍持久保存，启动前置主题与运行时一致，跟随系统响应系统深浅色变更。
- 启动：打开软件默认放映，桌面和移动端导航均把放映排首；未访问首页时不提前挂载首页。Alt+1–4 顺序改为放映、首页、探索、分类。
- 下拉框：移除 scrollIntoView 对外层页面的连带滚动；等待弹层定位后，只更新列表自身 scrollTop，避免第一次点击产生外部 scroll 导致立即关闭。保留键盘、外部点击/滚动、窗口失焦和全屏返回的关闭行为。
- 间距：板块标题与封面/内容保留至少 18px 间隔，覆盖最近上新等首页区块和探索内容。
- 保留框架、ENIAC 署名、应用图标、接口分数与排序、播放栏选集、全屏/进度相关修复。

验证：TypeScript、生产构建及浏览器组件回归；覆盖启动放映、主题升级和手选持久化、拼接热搜词、标题间距、下拉框第一次打开及内部滚动。原生窗口按键未实机操作验证。
