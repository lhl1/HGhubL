# 1.5.2 分数展示与排序

- 本次修改前备份：工作区 backups/20261112_163354_before_score_sort，保留 1.5.1 源码包、便携包及可运行目录，并记录 SHA256。
- 分数用于选片：封面右上角、详细列表、排行榜、详情和播放栏直接展示综合分；无有效分数显示“暂无评分”。播放栏可查看综合分和评分人数，只读 GET /api/videos/{id}/rating。
- 完整移除个人星级选择、登录后评分、提交评分按钮、前端提交函数及原生 api_rate 命令。上游 my/already 字段仅为输入类型兼容，不展示、不影响综合分。
- 首页按各原有板块分别排序；探索各视频分区、分类、搜索、标签和专题内作品、排行榜提供评分优先。专题集合和图文列表不具备作品评分，沿用原排序。
- 评分优先按本次已加载作品的接口 score 从高到低排列。数值字符串兼容；无评分和非法值排最后，同分保留原顺序。不伪造全站高分榜。继续加载会合并后重新排序。
- 分类评分优先使用最近上新同一分页源；切换分数/上新排序保留已加载页面，其他分类或排序变更照常重置源。榜单封面数字保留上游真实名次，界面说明显示顺序的变化。
- 点击已排序作品后，预览及播放上下文使用对应排序后的 ID 队列和索引。
- 播放栏选集、全屏隐藏、返回退出、播放进度和媒体节点保持原有修复逻辑。

验证：浏览器组件测试覆盖分数展示、无个人评分入口、分类/探索跨页排序、搜索播放上下文、榜单名次、首页和专题排序；全屏、选集与读取失败隔离使用模拟媒体/原生窗口。Rust 离线测试验证原生命令和其他功能；桌面原生窗口按键未实机操作验证。
