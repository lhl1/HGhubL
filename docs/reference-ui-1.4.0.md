# HGhub 1.4.0 · windows-client 界面与交互适配

日期：2026-11-12。参考源为用户提供的 `windows-client` 2.3.8；保留 HGhub 的 Tauri 2 / Rust / React / HLS 框架、业务接口、账号数据、播放修复和缓存策略。

## 备份

修改前备份：工作目录下 `backups/20261112_113520_before_reference_ui`，包含 1.3.0 源码包、便携包、完整工作目录和 `SHA256.json`。此前 1.2.1、1.3.0 交付均保留。退出新版，打开 `HGhub-optimized-1.3.0/HGhub.exe` 即可回退。

## 对齐内容

- 配色取自参考项目 `desktop.css` 和 `release.css` 的最终覆盖值：浅色背景 `#f6f7fa`、白面板、强调色 `#ed623e`；深色背景 `#15171c`、面板 `#1e2128`、强调色 `#ff835a`。主题支持跟随系统/浅色/深色，已有选择沿用。
- 桌面不再使用原 Fluent 独立标题栏；采用参考项目的 166px 侧栏、68px 顶部工具栏、独立右上角窗口按钮。小窗口侧栏缩为 140px，进一步窄化时仅显示图标。初始窗口 1240×860，最小 780×620，与参考配置一致。
- 无边框模式继续由 Tauri 原生窗口支持。空白工具栏和标题区可拖动，双击空白处最大化/还原；搜索框、表单和按钮不会触发拖动。最小化/最大化/关闭及八方向边缘缩放调用原生窗口 API；最大化与原生全屏隐藏缩放热区。
- 侧栏采用发现、排行榜、分类、追剧、记录、设置。追剧/记录分别打开实际收藏及观看记录；不新增另一份媒体库。原登录管理仍在“我的”资料区。
- 顶部搜索贯通所有页面，提交后退出当前堆栈并打开搜索结果，支持中文输入法与重复搜索；发现页提供推荐/短剧/漫剧频道切换。
- 分类页参考 `Explore` 和 `CategoryFilters`：快捷入口、猜你想搜、分类/排序、多行题材/状态选项、展开/收起、重置、结果计数与排列切换。分类与标签元数据来自 HGhub 真实接口，旧回包隔离沿用已验证的分页逻辑；有匹配作品时滚动触底自动续页，无匹配时保留手动加载，避免后台连续扫描。
- 排行榜参考 `Rankings`：标题区、分类行、榜型行、紧凑下拉筛选、带原始名次的横向卡片、列表/网格切换与刷新。切换分类清理题材选择，快速切榜只接受最新回包；保留上游真实名次，不在筛选后重新编号。
- 目录网格从文字覆在封面上的瀑布流改为参考项目的封面+下方标题/题材布局，保持 3:4 封面比例和统一留白。右键可添加/取消本地追剧。排列状态在目录间共享，临时切换不改持久默认值。
- 播放舞台采用参考项目的留白、圆角和纯黑画面背景；保留已修复的取址、HLS、播放恢复和控制功能。

## 数据边界

HGhub 与参考项目使用不同上游。没有把参考项目的 APK、Electron/JRE/JNI/FFmpeg、账号或签名协议接入 HGhub。

- 分类及最近更新/当前最热/原创热播使用 HGhub 的实际分类接口与官网正在使用的排序参数。
- 题材、完结状态筛选当前已加载的分类作品；可继续加载扩大范围，页面已明确标注。
- 排行榜仍提供 HGhub 上游实际支持的热播、推荐、潜力三个榜型。分类、题材和完结状态筛选本次榜单返回的作品，保留原始名次与指标。没有编造参考项目特有的预约榜、演员榜或筛选接口。
