# HGhub 1.4.1 全屏窗口与全屏播放

本轮保留 Tauri + Rust + React 框架及 1.4.0 的参考界面逻辑，仅调整播放呈现与返回行为。

修改前备份：工作目录 `backups/20261112_122150_before_immersive`，包含 1.4.0 源码压缩包、便携压缩包、完整可运行目录及 SHA256 清单。1.4.0 目录不覆盖，退出新版后可直接运行旧版回退。

## 使用

- 点击底部“全屏窗口”或按 T，进入占满当前窗口的沉浸模式；点击“全屏”或按 F，进入屏幕全屏。
- 进入即隐藏全部播放器控件。左上角标题/返回栏、右上角及右侧社交操作、左下角介绍、全局工具栏、窗口按钮、侧栏、缩放热区均隐藏。画面去掉圆角、装饰边框、信息渐变及中央暂停图标。
- 明确移动鼠标或点击画面时，短暂显示底部控制条；停止操作 1.2 秒后再次隐藏，暂停时同样生效。细微位置抖动不唤醒，连续慢速移动仍可正常唤醒；鼠标离开画面、窗口失焦时立即隐藏。闲置时同时隐藏鼠标指针。
- 拖动进度、音量或展开倍速菜单期间保持控件可用；结束操作后恢复自动隐藏。加载和播放错误反馈保留，错误状态仍可重试。
- 底部“返回普通窗口”、Esc、Alt+左箭头、浏览器返回键、鼠标返回键，优先退出全屏/全屏窗口，保留当前播放页；Backspace 仅在非编辑区域作为返回。焦点在倍速菜单或按钮上时同样优先退出。浏览器自身退出全屏也会恢复普通窗口。
- 返回不重新取址或重建播放器，不清空进度，不改变手动暂停状态。恢复普通窗口后保留原有返回页面逻辑。
- 嵌入播放器共享同一套闲置隐藏与返回控件。原生窗口全屏状态在桌面壳同步，工具栏隐藏后仍可正确退出。
