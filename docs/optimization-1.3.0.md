## 实际改动

- 首页、搜索、频道、帖子和评论分页使用带请求代次隔离的加载逻辑；新关键词不被旧请求阻挡，旧回包/旧错误不能污染新结果。分页去重覆盖单页重复项，空页停止加载，失败保留重试入口。
- 搜索支持中文输入法组合状态，回车确认候选词不会提前提交；清空搜索使未完成请求失效。
- 播放页不再向观看记录写入“仅取到地址但尚未观看”的条目；切集、暂停与离开时保存进度，显式传入的新集进度不会被归零。
- 修正本地喜欢、收藏、关注操作同步返回值不准确的问题；校验旧本地数据中的非法类型和数值。
- 收藏/历史突破原先仅加载 12 条的限制，按需增加，每批最多 4 个详情请求，已加载详情在页面内复用。
- 首页加载失败可重新加载；分类/搜索/帖子使用占位布局和明确的空状态；图片换源重置状态，空图和加载失败提供占位，避免空地址请求当前页面。
- 顶层页面首次进入才挂载；已进入页面继续保留状态。隐藏、被登录框或详情弹窗遮挡的播放器不会在异步取址完成后偷偷开始播放。
- 主播放器与正文内播放器共用 `VideoSurface`，统一资源释放和原生错误处理；HLS 按需加载，源切换/卸载销毁实例并解除媒体地址。
- HLS 增强缓冲目标 60 秒、标准模式 20 秒，缓冲字节目标分别为 32 MiB/20 MiB；暂停一分钟停止 HLS 继续取流，再次播放时刷新地址。这里是 hls.js 缓冲目标，不是应用总内存硬上限。
- 增加上一集按钮，Q/E 上一集/下一集，与按钮提示一致；进度条支持五秒键盘步进，没有时长时禁用。返回键优先关闭临时面板与全屏。
- Rust 封面缓存最多 240 项/64 MiB、30 分钟有效；播放列表缓存最多 60 项/16 MiB、5 分钟有效，按最近使用淘汰。重复的封面、背景和播放列表并发请求合并；清理缓存后旧的在途响应不会重新填回缓存。

浏览器回归使用隔离配置与合成媒体事件；真实取流检查直接运行 Rust 后端，不把这两类结果等同于长时间观看实测。Windows 1.3.0 发布程序已启动，读取到截图对应剧集播放进度 `00:08 / 03:27`，新增上一集、下一集、进度条控件存在，未出现加载错误。桌面键鼠自动化在当前系统先前返回过访问拒绝，因此不以自动拖动或手动切集为已验证结论。macOS/Android 未重新构建。

该 Windows x64 便携包采用 GNU 工具链构建，需要将附带的 `WebView2Loader.dll` 与 `HGhub.exe` 放在同一目录。依赖与原项目保持一致，系统仍需已有 WebView2 Runtime。
